# HuntLoan

A Rust + Solidity starter project.

## Structure

```
src/              Rust application
contracts/src/    Solidity smart contracts
contracts/test/   Foundry tests
```

## Quick Start

### Rust

```bash
cargo run
```

### Solidity

```bash
cd contracts
forge build
forge test -vv
```

## Requirements

- [Rust](https://rustup.rs/) 1.93+
- [Foundry](https://getfoundry.sh/)
